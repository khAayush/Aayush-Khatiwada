Full-Stack Web Application

ThreeSixty

IT Inventory Management & Support Platform — an all-in-one organisational tool with real-time chat, ticketing, and lost & found management.

MongoDB Express.js React Node.js Socket.IO Tailwind CSS Figma
The Problem

Organisations often juggle multiple disconnected tools — spreadsheets for inventory, email threads for support requests, and manual registers for lost items. This fragmentation leads to administrative overhead, slow response times, and data inconsistencies.

The Solution

ThreeSixty consolidates inventory management, a support ticketing system, real-time staff chat, and a lost & found module into a single cohesive dashboard. Role-based access ensures every stakeholder — admin, staff, and user — sees only what they need.

Key Features
—Real-time inventory tracking with category, location & status
—Ticketing system with priority levels and status workflows
—Live chat powered by Socket.IO for instant staff communication
—Lost & Found module with item reporting and claim management
—Role-based access control (Admin, Staff, User)
—Responsive dashboard designed in Figma with Tailwind CSS
Challenges
→Building a real-time chat system that scales with concurrent users across multiple rooms
→Designing a flexible RBAC system that cleanly separates Admin, Staff, and User permissions
→Keeping inventory state consistent across concurrent user sessions without race conditions
Lessons
↑Socket.IO namespaces and rooms simplify multi-channel real-time architecture significantly
↑Early MongoDB schema design prevents expensive data migrations during later development
↑A shared Figma design system reduces UI inconsistencies between prototype and implementation
