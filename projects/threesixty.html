ThreeSixty

IT Inventory Management & Support Platform — an all-in-one organizational tool with real-time features.

View on GitHub
MongoDB Express.js React Node.js Socket.IO Tailwind CSS Figma

Overview

ThreeSixty is a comprehensive IT management platform built to help organizations manage their hardware and software inventory alongside a full ticketing support system. The platform integrates real-time chat and a lost & found module into a single cohesive dashboard.

Problem

Organizations often juggle multiple disconnected tools — spreadsheets for inventory, email threads for support requests, and manual registers for lost items. ThreeSixty consolidates all of this into one platform, reducing administrative overhead and improving response times.

Key Features

  • Real-time inventory tracking with category, location, and status management
  • Ticketing system with priority levels, assignment, and status workflows
  • Live chat powered by Socket.IO for instant staff communication
  • Lost & Found module with item reporting and claim management
  • Role-based access control (Admin, Staff, User)
  • Responsive dashboard designed in Figma with Tailwind CSS

Tech Stack

The frontend is built in React with Tailwind CSS for rapid UI development, mirroring the Figma prototypes. The backend uses Express.js on Node.js with MongoDB as the database. Socket.IO handles all real-time communication channels, ensuring zero-latency chat and live ticket updates.

Outcome

ThreeSixty demonstrates full-stack capability — from database schema design to real-time features to polished UI — completed as a final-year project at Herald College Kathmandu.
