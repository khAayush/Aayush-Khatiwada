EasyDoc

Online doctor appointment booking app — patients browse doctors by specialty, view availability, and book, reschedule, or cancel appointments seamlessly.

MongoDB Express.js React Node.js Tailwind CSS JWT Figma
The Problem

In Nepal, booking a doctor appointment often means long phone queues or in-person visits just to secure a slot. There is no central digital platform where patients can browse doctors, check real-time availability, and manage their appointments — leading to wasted time and high no-show rates.

The Solution

A full-stack MERN application exposing a RESTful API with JWT authentication. Patients can browse doctor profiles, check real-time slot availability via a calendar interface, and manage appointments. Doctors get an admin dashboard to manage their own schedules, all backed by atomic MongoDB transactions to prevent double-booking.

Key Features
—Patient registration with secure JWT authentication
—Doctor profiles with specialties, availability, and ratings
—Real-time slot availability with calendar-based booking
—Appointment management — book, reschedule, cancel
—Doctor dashboard for managing personal schedules
—Responsive Figma-driven UI built with Tailwind CSS
Challenges
→Implementing real-time slot availability without race conditions causing double-bookings
→Designing a calendar UI that is both intuitive and information-dense for busy doctors
→Securing all patient and doctor data with proper JWT validation across every API route
Lessons
↑Figma-driven development dramatically reduces frontend rework by resolving ambiguity early
↑MongoDB transactions are essential for atomic appointment operations to prevent conflicts
↑Designing the API contract before frontend implementation prevents interface mismatches
